# Безопасность и приватность

## Что не следует публиковать

Не прикладывайте к публичным Issues и Discussions:

- резервные копии конфигурации роутера;
- пароли, токены, ключи SSH и cookie веб-интерфейса;
- реальные внешние IP-адреса, если они не нужны для диагностики;
- журналы, содержащие имена устройств, MAC-адреса или локальные пути пользователя.

Перед отправкой диагностических файлов замените персональные значения понятными
заглушками. Для сообщения об уязвимости используйте приватный канал GitHub Security
Advisories, а не публичную задачу.

Конвертер не записывает пароль роутера в создаваемый пакет. В графическом интерфейсе
пароль хранится только в памяти на время операции и очищается после завершения.
Запросы к роутеру не проходят через HTTP-прокси из окружения. Адрес с встроенными
логином и паролем отклоняется, чтобы они не попали в `manifest.json`.
Локальные резервные копии роутера исключены из репозитория правилом `.gitignore`.

## Передача пароля

По умолчанию автоматическая установка использует `http://` и передаёт пароль
web-интерфейса по локальной сети без шифрования. Это приемлемо только в доверенной
домашней сети. Если роутер поддерживает HTTPS, укажите адрес `https://...`.
Пароль, переданный параметром `--router-password`, может остаться в истории команд
и списке процессов; предпочтительнее запрос пароля или переменная окружения.
