# Zapret Keenetic Converter 0.6.0

Главное новшество — встроенный тестер стратегий Flowseal.

## Тестер стратегий

- Новая вкладка **Тест**: по очереди запускает `winws.exe` с каждой стратегией
  и проверяет HTTPS-доступность YouTube, Discord, Google и Cloudflare.
- Таблица результатов: сколько целей ответило, среднее время и вердикт.
  Лучшая стратегия выделяется; её можно сразу применить для конвертации.
- Тестер работает только в Windows, требует прав администратора и
  остановленного Zapret/Flowseal. Роутер не изменяется; запущенный тестер
  `winws.exe` всегда останавливается после проверки.
- Для командной строки добавлен `zapret-keenetic-test` и
  `py -3 -m zapret_keenetic.tester`.

## Интерфейс

- Поле WAN-интерфейса подсказывает `eth2.4`; значение VLAN можно ввести вручную.
- Настройки окна по-прежнему запоминаются, пароль роутера не сохраняется.
- После успешной конвертации автоматически подставляется новая папка результата,
  поэтому повторное нажатие «Конвертировать» не упирается в непустой каталог.
- Ошибка установки больше не называется ошибкой конвертации: результат остаётся
  на месте, а сообщение объясняет, что выбрать точный режим вместо гибридного.

## Совместимость

Целевые версии: nfqws2-keenetic 1.3.3, zapret2 v1.0.7. Проверено на Flowseal
1.10.4. Перед установкой проверяйте `REPORT.md` и сохраняйте резервную копию
роутера.
