# Zapret Keenetic Converter 0.4.1

Технический выпуск: исправления надёжности, безопасности и совместимости.
Новых обязательных шагов для пользователя нет.

## Важное

- Гибридный режим теперь применяет выбранные в конвертере WAN-интерфейс,
  IPv6, политику Keenetic, номер NFQUEUE и объединяет порты TCP/UDP со
  штатной конфигурацией nfqws2. Раньше эти параметры молча игнорировались.
- Минимальная версия Python — 3.10. На 3.9 запись результата падала с
  `TypeError` из-за параметра `newline` у `Path.write_text`.
- Прерывание установки (Ctrl+C или закрытие окна) теперь запускает откат,
  а окно не закрывается во время операции.
- Неудачная или строгая конвертация больше не оставляет непустую папку
  результата: сборка идёт во временном каталоге и переносится только при успехе.

## Исправления

- Списки с одинаковым именем из разных каталогов получают уникальные имена;
  повторный файл списка в одном профиле не дублируется.
- Смещение blob `+N@file` теперь действительно применяется к fake-шаблону.
- ZIP создаётся с прямыми слэшами и корректно распаковывается на Linux/OpenWrt.
- Установка работает и для профиля без списков.
- Неизвестные `%ПЕРЕМЕННЫЕ%` и неподдерживаемые режимы fooling попадают в
  диагностику; `hopbyhop`/`hopbyhop2` переносятся как `ip6_hopbyhop`/`ip6_hopbyhop2`.
- Запросы к роутеру не используют HTTP-прокси из окружения; адрес с логином и
  паролем отклоняется, чтобы секрет не попал в `manifest.json`.
- Пустой номер NFQUEUE больше не роняет графическое окно.
- Отчёт `report.json` включает сам себя; повторные `INFO / ipset-backup`
  не дублируются.
- `test_compatibility` пропускается без `lupa`, а не ломает весь набор тестов.

## Совместимость

Проверено с Flowseal 1.10.4 (`general.bat`, `general (ALT13).bat`), целевые
версии — nfqws2-keenetic 1.3.3 и zapret2 v1.0.7. Перед установкой по-прежнему
проверяйте `REPORT.md` и сохраняйте резервную копию роутера.
