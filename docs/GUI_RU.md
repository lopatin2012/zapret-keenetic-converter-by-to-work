# Графический конвертер для Windows, Linux и macOS

Графическое приложение позволяет выбрать стратегию Flowseal и получить готовый
комплект для Keenetic/OpenWrt без ручного ввода длинной команды.

В версии 0.6.0 есть вкладки **Конвертация**, **Установка**, **Тест**, **Журнал**.
На первой вкладке справа показаны выбранная стратегия и папка результата.
Раздел **Дополнительные параметры** открывает редкие настройки, под ним находится
**FAQ** с пояснениями. Сообщения о результате и предупреждениях появляются в
журнале после запуска.

## Быстрый запуск в Windows

Готовая Windows-сборка запускается без установки Python: скачайте ZIP на
[странице выпусков](../../../releases), распакуйте и откройте
`ZapretKeeneticConverter.exe`. Инструкция по скачиванию:
[DOWNLOAD_RU.md](DOWNLOAD_RU.md).

Если запускаете исходники, установите Python 3.10+ с Tk, распакуйте или
клонируйте репозиторий и откройте **Запустить конвертер.cmd**.

Если конвертер установлен через `pip`, его можно открыть командой:

```powershell
zapret-keenetic-gui
```

Универсальный способ:

```powershell
python -m zapret_keenetic.gui
```

На некоторых дистрибутивах Linux для графического окна дополнительно требуется
системный пакет `python3-tk`.

## Как пользоваться

### 1. Папка Flowseal

При запуске программа пытается сама найти корневую папку `zapret-discord-youtube`
рядом с исполняемым файлом, в `Downloads` и на `Desktop`. Если папка найдена,
она подставляется автоматически. Если нет — нажмите **Выбрать…** и укажите её
вручную: внутри должны быть `.bat`-профили, папки `bin` и `lists`.

Мастер просканирует папку и покажет только BAT-файлы, в которых удалось
распознать полноценную команду `winws.exe`. Служебные BAT-файлы без стратегии в
список не попадут.

Если Flowseal был обновлён после открытия программы, нажмите **Обновить**.

### 2. Стратегия

Первая найденная рабочая стратегия (обычно `general.bat`) выбирается
автоматически. Откройте список **Стратегия**, чтобы выбрать другую, например:

```text
general.bat
general (ALT11).bat
```

Сначала проверьте выбранный профиль на Windows через оригинальный Flowseal.
Конвертер переносит параметры, но не может определить, какая стратегия лучше
работает у конкретного провайдера.

### 3. Папка результата

Программа автоматически предлагает каталог вида:

```text
KeeneticZapret-converted/general-alt11-keenetic-20260813-123045/
```

В имени есть дата и время. Это защищает предыдущий результат от случайной
перезаписи. Папка показана в сводке справа; кнопка **Изменить папку…** позволяет
выбрать собственный пустой каталог.

Если выбранная папка уже содержит файлы, конвертация остановится. Удалять или
перезаписывать чужие файлы программа не будет. После успешной конвертации папка
открывается автоматически; это можно отключить флажком **Открывать папку
результата**.

Настройки окна сохраняются в `%APPDATA%\ZapretKeeneticConverter\settings.json`
(на Linux/macOS — в каталоге конфигурации пользователя). В файле нет пароля
роутера, только пути и выбранные параметры.

### 4. Тест стратегий

Вкладка **Тест** сравнивает стратегии на этом компьютере: по очереди запускает
`winws.exe` и проверяет HTTPS-доступность YouTube, Discord, Google и Cloudflare.
Лучшая стратегия выделяется в таблице; выберите строку и нажмите
**Применить выбранную**, чтобы подставить её для конвертации.

Тестеру нужны права администратора и остановленный Zapret/Flowseal. Он временно
перехватывает сетевой трафик, но не меняет роутер. Подробности и ограничения:
[Тестер стратегий](STRATEGY_TESTER_RU.md).

## Параметры окна

### Платформа

- **Keenetic / Entware** — пути начинаются с `/opt/etc/nfqws2`, дополнительно
  создаётся папка `web-import`;
- **OpenWrt** — пути начинаются с `/etc/nfqws2`.

### WAN-интерфейс

Это интерфейс подключения к провайдеру. Значение `eth3` является только частым
вариантом Keenetic, а `pppoe-wan` — примером OpenWrt. Часто встречаются также
`eth2.2`, `eth2.4`, `ppp0` и VLAN-интерфейсы вида `eth2.4`; список в поле —
подсказка, значение можно ввести вручную.

Проверьте интерфейс на роутере:

```sh
ip route get 1.1.1.1
```

Обычно нужно имя после `dev`. Возможные значения: `eth3`, `eth2.2`, `ppp0`,
`pppoe-wan`. При нескольких провайдерах или туннелях проверяйте фактический
маршрут.

### Игровые порты

- **Выключен** — не добавлять игровые диапазоны, соответствует
  `--game-filter disabled`;
- **TCP и UDP** — включить оба типа игровых профилей;
- **Только TCP** — включить только игровые TCP-профили;
- **Только UDP** — включить только игровые UDP-профили.

Оставляйте **Выключен**, если вам нужны только YouTube/Discord и выбранная
стратегия не требует игровых диапазонов.

### Режим IPSET

- **Загруженный список** — если `ipset-all.txt` пуст, использовать наполненный
  `ipset-all.txt.backup`;
- **Текущий ipset-all.txt** — использовать основной файл без автоматической
  замены.

Первый вариант соответствует типичной структуре репозитория Flowseal и выбран
по умолчанию.

### Политика Keenetic

Имя политики доступа Keenetic. Значение по умолчанию — `nfqws`.

- если такой политики на Keenetic нет, пакет обычно обрабатывает весь трафик;
- если политика существует и исключение выключено, обрабатываются устройства
  политики;
- если включено **Исключать устройства политики**, обрабатываются все, кроме
  устройств этой политики.

Для OpenWrt эти элементы отключаются.

### Номер NFQUEUE

По умолчанию `300`. Допустимы числа от `0` до `65535`. Меняйте номер только при
подтверждённом конфликте с другой службой NFQUEUE.

### Обрабатывать IPv6

Включено по умолчанию. При снятом флажке конвертер записывает
`IPV6_ENABLED=0`.

Не отключайте IPv6 только ради эксперимента, если провайдер и домашняя сеть его
используют: часть соединений может начать обходить ожидаемый маршрут.

### Строгий режим

Если включён, любое предупреждение делает конвертацию неуспешной. Режим полезен
при автоматической проверке и разработке. Обычному пользователю лучше сначала
оставить его выключенным и внимательно прочитать `REPORT.md`.

### Создать ZIP

Выключено по умолчанию. Если включить параметр, ZIP создаётся рядом с папкой
результата и подходит для хранения или отправки комплекта на другой компьютер.

## Автоматическая установка на Keenetic

На вкладке **Установка** флажок **Установить после конвертации** включает загрузку
готового результата прямо на роутер. Для OpenWrt эта функция отключена.

Заполните адрес web-интерфейса, пользователя и пароль, затем выберите режим:

- **Гибридный** — Discord из выбранной стратегии Flowseal, YouTube через
  адаптивную стратегию nfqws2;
- **Точный** — весь выбранный профиль без гибридного объединения; выбран по умолчанию.

Экспериментальные TLS clone и лимит fake-повторов по умолчанию выключены.
Их назначение объясняется в **FAQ**. Меняйте по одному параметру и сравнивайте
результат с исходной стратегией.

Перед записью мастер запросит подтверждение и создаст локальную резервную копию.
При ошибке загрузки или запуска прежняя конфигурация восстанавливается
автоматически. Пароль после завершения очищается и в файлы не записывается.

Полное описание: [AUTO_INSTALL_RU.md](AUTO_INSTALL_RU.md).

## Запуск конвертации

Нажмите **Конвертировать**. Во время работы отображается индикатор; закрыть окно
до завершения нельзя. После завершения папка результата открывается
автоматически (если включён флажок **Открывать папку результата**), а вкладка
**Журнал** показывает:

- путь результата;
- количество прочитанных и записанных профилей;
- число предупреждений;
- путь ZIP, если он создавался;
- диагностические сообщения.

Кнопки **Открыть результат** и **Открыть REPORT.md** доступны в сводке справа.
Сначала прочитайте `REPORT.md`.

Настройки окна сохраняются между запусками, поэтому повторная конвертация
занимает одно нажатие. Пароль роутера не сохраняется.

Для Keenetic результат содержит:

```text
result/
├── nfqws2.conf
├── lists/
├── blobs/
├── web-import/
│   ├── nfqws2.conf
│   ├── README.md
│   └── lists/*.list
├── REPORT.md
└── report.json
```

- для установки по SSH/SCP используются верхние `nfqws2.conf`, `lists/` и
  `blobs/`;
- для установки через веб-интерфейс используются только `web-import/nfqws2.conf`
  и `web-import/lists/`.

Подробный веб-импорт описан в [WEB_INTERFACE_RU.md](WEB_INTERFACE_RU.md).

## Если программа не запускается

### Windows показывает, что Python не найден

Установите актуальный Python и включите **Add Python to PATH**, затем закройте и
заново откройте Проводник/терминал. Проверьте:

```powershell
py -3 --version
```

или:

```powershell
python --version
```

### Окно сразу закрывается

Откройте PowerShell в папке конвертера и выполните:

```powershell
py -3 -m zapret_keenetic.gui
```

Текст ошибки останется в терминале. Не публикуйте вместе с ним пароли роутера.

### Список стратегий пуст

Проверьте, что выбрана корневая папка Flowseal, а не `bin`, `lists` или папка
самого конвертера. BAT-файл должен содержать запускаемую команду `winws.exe`.

### Выходной каталог не пуст

Нажмите **Конвертировать** ещё раз: для автоматически предложенного пути
программа подставит новую папку с датой и временем. Если папку выбирали вручную,
укажите новый пустой каталог или очистите старый. Существующие файлы программа
намеренно не удаляет.

### Установка не выполнена: нужен nfqws2.conf-opkg

Это ошибка **гибридного** режима: на роутере нет исходного конфига пакета.
Выберите на вкладке **Установка** режим **Точный** и повторите установку.
Конвертированный результат при этом уже сохранён в папке результата — его
можно открыть и установить повторно; заново конвертировать не обязательно.

### Конвертация завершилась с предупреждениями

Откройте `REPORT.md`. Предупреждение означает, что некоторый параметр нельзя
перенести однозначно, отсутствует нужный файл или найдено ограничение роутера.
Не устанавливайте результат вслепую.

## Соответствие интерфейса командной строке

| Поле окна | Параметр CLI |
|---|---|
| Папка Flowseal | `source` |
| Стратегия | `profile` |
| Папка результата | `--output` |
| Платформа | `--target` |
| WAN-интерфейс | `--interface` |
| Игровые порты | `--game-filter` |
| Режим IPSET | `--ipset-mode` |
| Обрабатывать IPv6 | отсутствие/наличие `--no-ipv6` |
| Политика Keenetic | `--policy-name` |
| Исключать устройства политики | `--policy-exclude` |
| Номер NFQUEUE | `--queue-num` |
| Строгий режим | `--strict` |
| Создать ZIP | `--archive` |
| Установить после конвертации | `--install` |
| Тест стратегий (вкладка **Тест**) | `python -m zapret_keenetic.tester` |
| Режим установки | `--install-mode` |
| Адрес nfqws2 | `--router-url` |
| Пользователь | `--router-user` |
| Пароль | интерактивный запрос / `--router-password` |
| Проверить YouTube и Discord | `--check-services` |

Графический интерфейс вызывает те же функции конвертации и установки, что и
CLI. Поэтому результат при одинаковых параметрах не зависит от способа запуска.
