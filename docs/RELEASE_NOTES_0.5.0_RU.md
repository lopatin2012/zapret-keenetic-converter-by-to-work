# Zapret Keenetic Converter 0.5.0

Выпуск про удобство: запустить программу и получить готовый результат с
минимумом действий.

## Быстрый сценарий

- Приложение само ищет папку Flowseal рядом с собой, в `Downloads` и на
  `Desktop`, и выбирает первую рабочую стратегию.
- Настройки окна запоминаются между запусками: папка, стратегия, интерфейс,
  политика, режим установки и адрес роутера. Пароль не сохраняется.
- После конвертации папка результата открывается автоматически. В сводке есть
  кнопки **Открыть результат** и **Открыть REPORT.md**.
- Для автоматической установки достаточно включить её один раз, ввести пароль
  при запуске и нажать **Конвертировать и установить**.

## Надёжность

- Сборка идёт во временном каталоге и публикуется только после успешной
  проверки; ошибка не оставляет неполный результат.
- Закрытие окна во время установки блокируется, Ctrl+C запускает откат.
- Повторные списки и совпадающие имена файлов обрабатываются без потери данных.
- Смещение blob `+N@file` применяется к fake-шаблону.
- Профили во вложенной папке Flowseal корректно разрешают `%~dp0`, `%BIN%` и
  `%LISTS%` относительно своего каталога.
- ZIP использует прямые слэши и корректно распаковывается на Linux/OpenWrt.
- Запросы к роутеру не используют HTTP-прокси; адрес с логином и паролем
  отклоняется.

## Внутренние изменения

- Общий модуль формата `nfqws2.conf` для точного и гибридного режимов.
- Парсер `.bat`, рендеринг результата и хранение настроек вынесены в отдельные
  модули; версия приложения и целевые версии nfqws2/zapret2 — в одном месте.
- CI проверяет Python 3.10, 3.12 и 3.14, запускает тесты, GUI-самопроверку и
  `ruff`; отдельная еженедельная проверка конвертирует свежий Flowseal и
  сверяет контракт `nfqws2.conf` с upstream.
- Добавлены тесты на прерывание, очистку, коллизии имён, ZIP, смещения blob,
  установку без списков, настройки и автоопределение.

## Совместимость

Целевые версии: nfqws2-keenetic 1.3.3, zapret2 v1.0.7. Проверено на Flowseal
1.10.4. Перед установкой по-прежнему проверяйте `REPORT.md` и сохраняйте
резервную копию роутера.
